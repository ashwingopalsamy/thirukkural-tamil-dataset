# Roadmap

Planned work, in order. No dates.

1. Hugging Face dataset (next): publish the 24 Parquet tables, the card and Croissant metadata from `python -m tkcore.release`.
2. Kaggle dataset: the same tables with a Kaggle dataset card.
3. Zenodo DOI: archive each tagged release and add the DOI to `CITATION.cff`.
4. PyPI package: install `tkcore` with `pip` to load the tables and run the agent tools.
5. Directory links: entries in awesome lists for Tamil and NLP datasets, and external links from Wikipedia and Wikidata.
6. Search indexing: submit the sitemap to Google Search Console and Bing Webmaster Tools, and announce updates with IndexNow.
