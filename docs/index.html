What is the Thirukkural Tamil dataset?

It is the Tamil text of all 1,330 kurals of the Thirukkural, in 133 chapters and three books, with ids tk:0001 to tk:1330. Each kural has a list of its sources and a sha256 of its text. English translations, Parimelazhagar's commentary and a metre analysis are joined to every kural.

Where does the Tamil text come from?

Each kural was compared letter by letter across six digital sources. Where they differ, it was checked against three 19th-century printed editions, and each decision is recorded in a ledger. A kural page lists its sources and the sha256 of its text, so you can check what you copy.

Which English translations are included?

Three: G. U. Pope (1886), W. H. Drew and John Lazarus, and V. V. S. Aiyar (1916). Each is a separate table joined to the kural by id. Parimelazhagar's Tamil commentary and a metre analysis of every foot are separate tables too, so you can load only what you need.

Which file formats can I download?

Rows are JSONL files in the repository. Parquet is built from them by a script, and a SQLite database for the agent tools is built the same way. BGE-M3 vectors ship as one NumPy file, and a Croissant file describes the whole dataset for machine readers.

FormatWhereWhat

Parquetdist/hf/data/, built by python -m tkcore.release24 tables.

How do I load it in Python?

Read the kurals table straight from GitHub with pandas, as below. It has one row per kural, with its id, number, chapter, Tamil lines, status and sha256. The other tables join to it on the kural id, and the FAQ shows the same load with Hugging Face datasets.

import pandas as pd

base = "https://raw.githubusercontent.com/ashwingopalsamy/thirukkural-tamil-dataset/main"
kurals = pd.read_json(f"{base}/data/core/kurals.jsonl", lines=True)

What licence does the data use?

The Tamil text, its structure and the three English translations are CC0-1.0. The Parimelazhagar commentary table is MIT, with credit to its carrier, and the Wikisource commentary and readings are CC-BY-SA-4.0. Each table keeps its own licence, and the licensing page lists them all.

How do I cite it?

Cite the dataset with its version, as in the entry below. To cite one kural, add its id and its text_sha256 from the kural page. The CITATION.cff file in the repository holds the same details for tools that read it.

@dataset{gopalsamy_thirukkural_2026,
  author  = {Gopalsamy, Ashwin},
  title   = {Thirukkural Tamil Dataset},
  version = {1.0.0},
  year    = {2026},
  url     = {https://thirukkural.ashwingopalsamy.in/},
  license = {CC0-1.0}
}

How is the Thirukkural arranged into books and chapters?

The Thirukkural has three books, அறத்துப்பால், பொருட்பால் and காமத்துப்பால், in 133 chapters of ten kurals each. Chapters 1 to 38, 39 to 108 and 109 to 133 make up the three books in order. Each chapter below links to a page with all ten couplets and their English translations.
